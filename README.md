# 東京圏すみか図鑑

東京都（島しょ部を除く）の全648駅と、神奈川・埼玉・千葉のうち都心の主要6駅（東京・大手町・新宿・渋谷・池袋・品川）のどれかまで60分以内の639駅、計1,287駅を、家賃・通勤・治安・子育て・公園・買い物・グルメ・静けさ・高台（水害）・人気・交通の視点で比べられる3D地図と引っ越しガイドです。

公開ページ: https://skikkh.github.io/tokyo-sumika/
