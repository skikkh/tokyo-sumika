# 東京すみか図鑑

東京都（島しょ部を除く）の648駅を、家賃・通勤・治安・子育て・公園・買い物・グルメ・静けさ・高台（水害）・人気・交通の視点で比べられる3D地図と引っ越しガイドです。

公開ページ: https://skikkh.github.io/tokyo-sumika/

## データの出典とライセンス

- 国土交通省 国土数値情報「行政区域（2025年）」「鉄道（2024年）」「駅別乗降客数（2023年度）」（CC BY 4.0）を加工して使用
- 国土地理院 標高タイル（数値標高モデル）を加工して使用
- 地図データの一部（公園・水面・河川・道路・生活施設・駅名のよみ）は © OpenStreetMap contributors。`data/geo.json` のうちOpenStreetMap由来の部分は Open Database License（ODbL）で提供します
- 警視庁、東京都、総務省、各区市町村の公表統計
- 家賃の参考値: SUUMO・LIFULL HOME'S の家賃相場（2026年9月取得）。駅の家賃の一部は当サイトの推計です
- 人気・評判: SUUMO住みたい街ランキング2026、LIFULL HOME'S住みたい街ランキング2026、いい部屋ネット街の住みここちランキング2026（各社の公式発表）

スコアと推計値は物件探しの目安です。実際の家賃・治安・災害リスクは物件ごとに現地と公式情報で確認してください。
